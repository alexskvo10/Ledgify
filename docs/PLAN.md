# Ledgify — идея, аудит и план работ

## 1. Идея

**Ledgify** — спокойный личный трекер подписок и регулярных платежей для Windows и Android.
Отвечает на три вопроса:

1. **Сколько я трачу?** Итог месяца в одной основной валюте, прогноз на год, разбивка по категориям.
2. **Когда следующее списание?** Календарь месяца с иконками сервисов и напоминания заранее.
3. **От чего можно отказаться?** Самые дорогие подписки, триалы, которые скоро станут платными, бюджет.

Принципы:
- **Офлайн и приватно.** Данные лежат только на устройстве (Hive). В сеть приложение ходит только за курсами валют и только по кнопке.
- **Одно действие — один экран.** Добавить, посмотреть или отменить подписку можно за пару касаний.
- **Честные цифры.** Разные валюты пересчитываются в основную по курсам, которые видит и может поправить пользователь. Отменённая подписка перестаёт «тратить» с даты отмены.

## 2. Аудит исходного состояния (до работ)

| # | Проблема | Где |

## 3. Архитектура (после работ)

```
lib/
  main.dart                 точка входа: хранилище → провайдеры → MaterialApp
  app_info.dart             версия и название (одно место)
  theme/
    tokens.dart             отступы, радиусы, длительности, типографика
    palette.dart            семантические цвета (ThemeExtension) для светлой и тёмной темы
    app_theme.dart          сборка ThemeData из токенов
  l10n/
    strings.dart            строки EN/RU + плюрализация + форматтеры дат/денег
  models/
    subscription.dart       подписка, периодичность, статусы, категории, математика списаний
    currency.dart           справочник валют и пересчёт по курсам
    presets.dart            популярные сервисы для быстрого заполнения
  data/
    storage.dart            открытие Hive-ящиков и перенос старых файлов из «Документов»
    sub_repository.dart     CRUD подписок
    backup.dart             экспорт/импорт JSON (версионированный формат)
    demo_data.dart          демо-подписки (только по явному выбору)
    rates_client.dart       загрузка курсов из open.er-api.com (по кнопке)
  state/
    settings_provider.dart  тема, язык, основная валюта, курсы, бюджет, онбординг
    subs_provider.dart      список подписок + производные цифры в основной валюте
  widgets/                  компоненты дизайн-системы
  screens/                  home_shell, calendar, list, statistics, settings, onboarding
```

Поток данных: `Hive → Repository → Provider (ChangeNotifier) → UI`. UI не ходит в Hive напрямую.
`SubsProvider` слушает `SettingsProvider`: при смене основной валюты или курсов все итоги пересчитываются.

## 4. План работ

### Этап A — фундамент
- [x] A1. Аудит и этот план.
- [x] A2. Дизайн-система: токены, палитры светлой и тёмной темы, типографика, компоненты → `docs/DESIGN_SYSTEM.md`.
- [x] A3. Локализация всего интерфейса (EN/RU), русская плюрализация, даты и деньги по локали.

### Этап B — механики (починка)
- [x] B1. Математика списаний без перебора дней: интервал «каждые N недель, месяцев или лет», дата окончания.
- [x] B2. Мультивалютность: основная валюта, курсы (по умолчанию, ручная правка, загрузка из сети), все итоги в основной валюте.
- [x] B3. Отмена подписки фиксирует дату окончания; триал сам становится активной подпиской после даты первого списания.
- [x] B4. Бюджет в настройках, прогресс в календаре и статистике.
- [x] B5. Удаление с отменой (Undo) через один общий путь; «Удалить всё» без воскрешения демо-данных.
- [x] B6. Настоящий экспорт/импорт JSON (файл и буфер обмена), с проверкой формата.
- [x] B7. Хранилище в папке приложения, перенос старых файлов.

### Этап C — полезные функции
- [x] C1. Напоминания в приложении: «за N дней» для каждой подписки, блок «Скоро спишется» в календаре.
- [x] C2. Быстрое добавление по пресетам популярных сервисов.
- [x] C3. Список платежей месяца под календарём (на широком окне — справа).
- [x] C4. Единый экран «Подписки» с поиском, фильтром статуса и сортировкой; иконка поиска ведёт туда.
- [x] C5. Статистика: тренд за 6 или 12 месяцев, топ дорогих, пустые состояния (ближайший платёж — в календаре и списке).
- [x] C6. Горячие клавиши на Windows: Ctrl+N, Ctrl+F, Ctrl+1/2/3, ←/→.
- [x] C7. Онбординг с выбором «начать с нуля» или «посмотреть на демо-данных».
- [x] C8. Иконка приложения, название окна и ярлыка, минимальный размер окна.
