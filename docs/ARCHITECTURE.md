# Архитектура Ledgify

## Стек и почему он такой

| Что | Чем | Почему |
|---|---|---|
| UI | Flutter (Material 3 + своя дизайн-система) | один код для Windows и Android |
| Хранилище | Hive (ящики `subscriptions`, `settings`) | быстро, офлайн, без генерации кода: запись — простой `Map` |
| Состояние | provider + `ChangeNotifier` | два источника правды, этого хватает с запасом |
| Графики | fl_chart | столбцы и кольцо |
| Форматы | intl + flutter_localizations | деньги и даты по языку, русская плюрализация, календарь и поля ввода на русском |
| Сеть | `dart:io` HttpClient | один запрос курсов по кнопке, без лишней зависимости |

## Слои

```
UI (screens/, widgets/)
   │  читает через context.watch / context.read
   ▼
State (state/)  SettingsProvider ──слушает── SubsProvider
   │  вызывает
   ▼
Data (data/)    SubRepository · storage.dart · backup.dart · rates_client.dart · demo_data.dart
   │
   ▼
Hive-файлы в папке приложения: %APPDATA%\Ledgify\Ledgify\data (Windows)
  имя папки берётся из CompanyName/ProductName в windows/runner/Runner.rc —
  не менять без миграции данных
```

UI никогда не ходит в Hive напрямую. Все суммы, которые отдаёт `SubsProvider`, уже пересчитаны
в основную валюту; при смене валюты или курсов `SettingsProvider` оповещает `SubsProvider`,
и экраны перерисовываются.

## Модель

`Subscription` (неизменяемая) — `lib/models/subscription.dart`:

| Поле | Смысл |
|---|---|
| `amount`, `currency` | сумма одного списания и её валюта (ISO-код) |
| `cycle` + `interval` | неделя / месяц / год / разово × «каждые N» |
| `firstPayment` | опорная дата; у пробной подписки это первый платный день |
| `endDate` | последний возможный день списания (ставится при отмене) |
| `status` | `active` · `trial` · `canceled` · `archived` |
| `remindDaysBefore` | напоминание за N дней, `null` — выключено |
| `category`, `accentColor`, `icon`, `notes` | оформление и заметки |

**Математика списаний.** k-е списание вычисляется напрямую (`опора + k·период`), без перебора
дней, поэтому далёкие месяцы и длинные интервалы считаются мгновенно. Даты складываются
календарно (`DateTime(y, m, d + n)`), а не через `Duration`, поэтому переход на летнее время не
сдвигает платёж на соседний день. 31-е число в коротком месяце становится последним днём месяца
и потом возвращается на 31-е; 29 февраля в невисокосный год становится 28-м.

**Что куда входит:**

| Статус | Календарь и история | Прогноз, категории |
|---|---|---|
| active, trial | да | да |
| canceled | да, до `endDate` | нет |
| archived | нет | нет |

Пробная подписка сама становится активной, когда наступает её первый платный день (при запуске).

## Хранилище и совместимость

- `storage.dart` открывает Hive в папке приложения. Сборки до 1.0 писали файлы прямо в «Документы».
  При первом запуске они **копируются**, а оригиналы удаляются только после успешного открытия копий.
  `settings.hive` удаляется, только если в нём есть ключи Ledgify: такое имя может быть и у чужого
  приложения на Hive.
- `Subscription.fromMap` читает и старый формат (индексы enum, свободный `currencySymbol`,
  булево `notifications`). Сломанная запись пропускается, приложение не падает.
- Настройки старых версий (`defaultCurrency`-символ, `monthly_budget`, `onboarding_complete`)
  подхватываются автоматически.

## Резервная копия

JSON-формат (`data/backup.dart`), версия формата `1`:

```json
{ "app": "ledgify", "format": 1, "exportedAt": "…", "baseCurrency": "RUB",
  "subscriptions": [ { "id": "…", "name": "Netflix", "amount": 15.49, "currency": "USD",
                       "cycle": "monthly", "interval": 1, "firstPayment": 1767225600000, … } ] }
```

Экспорт кладёт JSON в буфер обмена, а на Windows ещё и в файл `Документы\Ledgify\ledgify-backup-ГГГГ-ММ-ДД.json`.
Импорт берёт JSON из буфера обмена и добавляет или заменяет записи по `id`. Копии более новой версии
формата отклоняются с понятным сообщением.

## Курсы валют

Хранятся как «единиц за 1 USD». Встроенные примерные значения работают офлайн; их можно поправить
вручную или загрузить с `open.er-api.com` (бесплатно, без ключа, по кнопке). В запросе нет никаких
данных пользователя. Android-манифест содержит разрешение `INTERNET` только ради этого.

## Карта файлов

```
lib/
  main.dart                точка входа
  app_info.dart            версия (сверяется с pubspec тестом)
  theme/                   tokens, palette, app_theme — см. DESIGN_SYSTEM.md
  l10n/strings.dart        все строки EN/RU, плюрализация, форматтеры денег и дат
  models/                  subscription, currency, presets
  data/                    storage, sub_repository, backup, rates_client, demo_data
  state/                   settings_provider, subs_provider
  widgets/                 ui (базовые компоненты), sub_tile, sub_detail, sub_form,
                           sub_actions (единая точка действий), budget, service_avatar, empty_state
  screens/                 home_shell, calendar, list, stats, settings, onboarding
test/                      модель, валюты и бэкап, провайдер, миграция хранилища,
                           сценарии через виджеты, рендер всех экранов

windows/runner/            заголовок окна, минимальный размер (WM_GETMINMAXINFO), ресурсы
```

## Тесты

| Файл | Что проверяет |
|---|---|
| `subscription_test.dart` | периодичность, 31-е, 29 февраля, летнее время, интервалы, дата отмены, сериализация и старый формат |
| `currency_backup_test.dart` | пересчёт валют, разбор сумм, бэкап туда-обратно, отказ на мусоре |
| `provider_test.dart` | итоги в основной валюте, бюджет при смене валюты, архив и отмена, триалы, отмена удаления, напоминания, миграция настроек |
| `storage_test.dart` | перенос старых файлов, чужой `settings.hive` не трогается |
| `flows_test.dart` | добавление через форму, «не сохранять?», удаление и «Вернуть», свайпы (вправо — изменить, влево — удалить), архив, поиск, бюджет, экспорт и импорт, отмена подписки |
| `screens_test.dart` | все экраны × тема × язык × размер без переполнений; эффекты наведения мыши; PNG при `LEDGIFY_SCREENSHOTS=1` |
| `app_info_test.dart` | версия в коде = версия в pubspec |

Особенность тестов на виджетах: запись в Hive — настоящий ввод-вывод, а тестовые часы «поддельные».
Поэтому сценарии дают диску доработать через `tester.runAsync` (хелпер `settle`), а тесты экранов не
закрывают ящики в конце: у каждого теста свои ящики.
