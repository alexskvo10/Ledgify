# Дизайн-система Ledgify

Короткое правило: **виджеты не знают конкретных цветов и чисел**. Они берут *роль* из палитры
(`context.palette.textSecondary`) и *токен* из шкалы (`Space.l`, `Radii.card`, `TextStyles.callout`).
Благодаря этому тёмная и светлая тема работают одинаково, а правка дизайна — это одна строка.

Код: [`lib/theme/tokens.dart`](../lib/theme/tokens.dart), [`lib/theme/palette.dart`](../lib/theme/palette.dart),
[`lib/theme/app_theme.dart`](../lib/theme/app_theme.dart), компоненты — [`lib/widgets/ui.dart`](../lib/widgets/ui.dart).

---

## 1. Характер

**«Спокойная бухгалтерия»**: тёмный интерфейс по умолчанию, мягкое зелёное свечение в углу окна,
крупная итоговая сумма, минимум линий. Деньги — главное, поэтому цифры набраны моноширинными
(табличными) цифрами, чтобы столбцы не «прыгали». Цвет несёт смысл, а не украшает:

| Цвет | Значение |
|---|---|
| Зелёный (accent) | бренд, активное, выбранное, «всё в порядке» |
| Оранжевый (warning) | скоро списание, месяц тяжелее обычного |
| Красный (danger) | удаление, перерасход бюджета, отменённая подписка |
| Синий (info) | пробный период |
| Серый (tertiary) | архив, второстепенное |

## 2. Цвет

Палитра — `ThemeExtension<Palette>`, две версии: `Palette.dark` и `Palette.light`.

| Роль | Тёмная | Светлая | Где |
|---|---|---|---|
| `bg` | `#0E0F13` | `#F2F2F7` | фон окна (+ градиент `glow`) |
| `surface` | `#17181E` | `#FFFFFF` | карточки, строки |
| `surfaceHover` | `#1D1F27` | `#F8F8FB` | наведение мыши |
| `raised` | `#1C1D24` | `#FFFFFF` | шторки, диалоги, меню |
| `sunken` | `#23252E` | `#EDEDF2` | поля ввода, неактивные чипы |
| `stroke` / `strokeStrong` | `#2A2C36` / `#3A3D4A` | `#E0E0E6` / `#C7C7CE` | обводки, разделители |
| `textPrimary` | `#F5F6FA` | `#1C1C1E` | основной текст |
| `textSecondary` | `#A0A3B1` | `#5E5E63` | подписи |
| `textTertiary` | `#737786` | `#6E6E78` | подсказки, заголовки секций |
| `accent` | `#34C759` | `#34C759` | заливки, выделение, графики |
| `accentText` | `#3DD266` | `#1B7F37` | зелёный **текст** |
| `accentFill` | `#1B8A3B` | `#1B8A3B` | фон кнопок с белым текстом |
| `danger` / `warning` / `info` | `#FF453A` / `#FF9F0A` / `#0A84FF` | `#D70015` / `#B35600` / `#0066CC` | состояния |

**Контраст (WCAG).** Фирменный `#34C759` с белым текстом даёт только 2,2:1 — нечитаемо. Поэтому
у зелёного три роли: `accent` для фона и графики, `accentText` для текста (5,1:1 в светлой теме),
`accentFill` для кнопок с белой надписью (4,4:1). Все текстовые роли проверены: основной и
вторичный текст ≥ 6:1, третичный ≥ 4:1, цвета состояний ≥ 4,3:1.

**Оттенки.** `palette.tint(color)` — полупрозрачная подложка цветного элемента (16 % в тёмной,
12 % в светлой теме). Используется для выбранных чипов, тегов статуса, плашек.

**Цвета категорий** заданы в `SubCategory` и одинаковы в обеих темах — это «метки», а не текст.

## 3. Типографика

Шрифт — **Segoe UI** (системный на Windows; на Android автоматически Roboto), эмодзи — Segoe UI Emoji.
Каждый стиль сам несёт семейство шрифта: темы диалогов и кнопок *заменяют* стиль текста, а не
дополняют его, и без этого часть подписей упала бы на шрифт по умолчанию.

| Токен | Размер / насыщенность | Где |
|---|---|---|
| `display` | 44 / 800, табличные цифры | итог месяца |
| `title1` | 24 / 700 | имя в карточке, онбординг |
| `title2` | 20 / 700 | заголовки экранов и шторок, метрики |
| `headline` | 16 / 600 | имя подписки в строке |
| `body` | 15 / 400 | абзацы |
| `callout` | 14 / 500 | кнопки, строки настроек |
| `subhead` | 13 / 500 | чипы, вторичные подписи |
| `footnote` | 12 / 400 | метаданные |
| `caption` | 11 / 700, капс, разрядка 0,8 | заголовки секций |
| `micro` | 10 / 600 | теги, ячейки календаря |
| `amount` | 15 / 700, табличные цифры | суммы в строках |

## 4. Пространство, форма, движение

- **Отступы** — шкала с шагом 4: `xxs 2 · xs 4 · s 8 · m 12 · l 16 · xl 20 · xxl 24 · xxxl 32`, поля страницы 16–20.
- **Радиусы**: `xs 6` теги · `s 10` чипы · `m 14` поля, кнопки, дни календаря · `l 20` карточки · `xl 28` шторки и диалоги · `pill` пилюли.
- **Глубина**: плоские поверхности с обводкой 1 px. Тень есть только у того, что парит: кнопка «Добавить», диалог, шторка.
- **Движение**: `fast 150 мс` наведение и нажатие · `base 220 мс` смена выбора · `slow 350 мс` смена вкладок · `counter 550 мс` счётчик суммы. Кривые — `easeOutCubic` на вход, `easeInCubic` на выход.
- **Раскладка**: колонка контента не шире 760 px; с 1000 px календарь делится на сетку и список платежей справа; шторки не шире 560 px; диалоги 380 px; минимальное окно Windows 420×640.
- **Зоны нажатия**: не меньше 40×40 px (иконки-кнопки), кнопки высотой 48, чипы 34.

## 5. Компоненты

| Компонент | Назначение | Правила |
|---|---|---|
| `AppCard` | контейнер строки или блока | `surface` + обводка, радиус `l`; при `onTap` появляются наведение и волна |
| `SectionLabel` | заголовок группы | капс `caption`, цвет `textTertiary`, справа можно положить действие |
| `AppChip` | фильтр или одиночный выбор | неактивный — `sunken`; выбранный — оттенок цвета + обводка; вибро-отклик |
| `AppIconButton` | круглая иконка 40 px | **всегда** с подсказкой: она же подпись для экранного диктора |
| `AppButton` | основное, вторичное или опасное действие | высота 48; основное — `accentFill` + белый текст; неактивное — 50 % прозрачности |
| `StatusTag` | статус подписки | не показывается для «Активна», чтобы не шуметь |
| `ServiceAvatar` | иконка сервиса | градиент цвета сервиса; буквы автоматически белые или чёрные по яркости; отменённые и архивные обесцвечены |
| `SubTile` | строка подписки | аватар · имя + тег · «цикл · категория» · сумма · когда списание (оранжевым, если ≤ 3 дней) |
| `SheetFrame` + `showAppSheet` | шторка снизу | ручка, заголовок + крестик, прокрутка, закреплённая кнопка внизу; у форм протягивание вниз отключено, чтобы не потерять ввод |
| `confirm()` | подтверждение | только для необратимого («Удалить всё»); обычное удаление обходится без диалога, там есть «Вернуть» |
| `toast()` | уведомление | плавающее, одно за раз; с действием висит 5 с, без действия 3 с |
| `EmptyState` | пустой экран | иконка в оттенке, заголовок, одна фраза, максимум одно действие |
| `BudgetBar` | бюджет | тонкая полоса; зелёная, при перерасходе красная; справа «Осталось» или «Перерасход» |
| `AppMark` | логотип | рисуется кодом, та же форма в иконке приложения (`tool/make_icons.py`) |

## 6. UX-принципы и сценарии

1. **Ничего не теряется молча.** Удаление и архивация сразу показывают «Вернуть». Форма с изменениями
   при закрытии спрашивает «Не сохранять?». «Удалить всё» — единственное необратимое действие, и у
   него есть подтверждение с советом сначала сохранить копию.
2. **Ошибки — рядом с полем**, а не всплывашкой: «Введите название», «Введите сумму больше 0».
3. **Разумные значения по умолчанию.** Валюта формы — основная валюта; дата — сегодня; напоминание —
   за 1 день; пресет популярного сервиса заполняет название, иконку, цвет, категорию и период.
4. **Один путь к действию.** Удаление, архив, карточка и форма открываются одними функциями
   (`widgets/sub_actions.dart`) с любого экрана, поэтому ведут себя одинаково.
5. **Клавиатура — полноправный ввод на Windows**: Ctrl+N, Ctrl+F, Ctrl+1/2/3, ←/→, Esc; подсказки
   с сочетаниями показываются при наведении.
6. **Демо-данные только по желанию** — в онбординге, на пустом экране и в настройках.

Карта экранов:

```
Онбординг (3 слайда, RU/EN) ─┬─ «Начать с нуля»
                             └─ «Посмотреть на примере» (демо)
Главное окно
 ├─ Календарь: месяц ← → · итог · «тяжелее/легче обычного» · бюджет · «Скоро списание»
 │            · сетка с тепловой подсветкой · платежи месяца (справа на широком окне)
 ├─ Подписки: поиск (Ctrl+F) · фильтр статуса · сортировка · свайп влево = удалить
 ├─ Статистика: в месяц / в год / активных · бюджет · расходы за 6/12 мес · категории · самые дорогие
 ├─ «+ Добавить подписку» (Ctrl+N) → форма в шторке
 ├─ Карточка подписки → Изменить · В архив · Удалить
 └─ Настройки: тема · язык · основная валюта · курсы · бюджет · резервная копия · демо · удалить всё · горячие клавиши
```

## 7. Доступность

- Контраст текста по WCAG (см. раздел 2).
- У всех иконок-кнопок есть подписи (`tooltip` + `Semantics`); у дней календаря озвучивается дата,
  число платежей и сумма; чипы сообщают «выбрано».
- Цвет никогда не единственный носитель смысла: статус подписан словом, перерасход — текстом.
- Анимации короткие (≤ 550 мс), без мигания.

## 8. Как проверять

`LEDGIFY_SCREENSHOTS=1 flutter test test/screens_test.dart` рендерит все экраны
(тёмная и светлая тема × RU/EN × телефон 390×844 и десктоп 1280×800) в `build/screens/`
со шрифтами Windows. Без переменной окружения тот же тест проверяет, что нигде нет переполнения
раскладки и исключений.
