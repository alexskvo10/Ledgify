## Что не проверено автоматически

- Запуск на реальном Windows и Android-устройстве. Скриншоты сделаны рендером в тестах, а не с экрана.
  Нужен ручной прогон: см. чек-лист ниже.
- Загрузка курсов с open.er-api.com (сетевой вызов в тестах не делается).
- Системный диалог выбора даты и выпадающее меню валют на Android.

### Чек-лист ручной проверки (5 минут)
1. Первый запуск → онбординг → «Посмотреть на примере».
2. Календарь: ← →, «К текущему месяцу», тап по дню с несколькими платежами.
3. «+ Добавить подписку» → пресет → сумма → сохранить; открыть карточку → «Изменить» → статус «Отменена».
4. Свайп влево в списке → «Вернуть».
5. Настройки → тема «Светлая», язык English → вернуть; «Курсы валют» → «Обновить».
6. «Сохранить резервную копию» → «Удалить все подписки» → «Загрузить из буфера обмена».
7. Windows: уменьшить окно до минимума, проверить Ctrl+N, Ctrl+F, Ctrl+1/2/3.
